# World News — Tuesday 24 November 2026

A program that writes one image summing up 24 November 2026's world news:
Russia's "Sputnik-S" nuclear space weapon, Kyiv region strikes, Ukraine
sinking a Russian warship off Libya, Nvidia bringing back Jensen Huang,
Iran vowing to confront the US naval blockade, and the Indonesia factory
fire toll confirmed at 24.

## Run

```sh
python3 main.py
```

Writes `entry.png` (1024×1024, PNG) to `/output` — or to
`$MAKEFUN_OUTPUT_DIR` when that is set. No network, no extra packages:
Python 3.13 standard library only. Running it twice produces
byte-identical output.

## Entry

Built for the [make.fun](https://make.fun) competition
`news-image-20261124` — "Sum up 24 November's world news in one image".
